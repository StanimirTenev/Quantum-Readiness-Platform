# Scenario Engine

## What this service does
- Provides predefined scenario multipliers for quantum-risk context.

## Current role in the prototype
- Partially implemented service supporting scenario lookup.

## Main endpoints or functions
- `GET /health`
- `GET /scenarios`

## Inputs / outputs
- Input: HTTP requests (no payload required).
- Output: JSON service status and scenario-to-multiplier mapping.

## Current status
- Partially implemented.

## Known limitations
- No scenario execution endpoint is currently implemented.
